# Word Definer - Chrome Extension

A simple Chrome extension that allows you to quickly look up the definition of a word on any webpage.

## Description

This extension enhances your browsing experience by providing an instant dictionary. When you double-click a word on a webpage, a small pop-up window appears with the word's definition, phonetic transcription, and an option to hear it pronounced. This is perfect for readers, students, and anyone who loves to learn new words.

## Features

-   **Instant Word Lookup**: Double-click any word to get its definition.
-   **Phonetic Transcription**: See how the word is pronounced.
-   **Audio Pronunciation**: Click a button to hear the word spoken.
-   **Simple & Lightweight**: The extension is designed to be unobtrusive and fast.

## Installation

1.  Clone this repository or download the source code as a ZIP file.
2.  Open Google Chrome and navigate to `chrome://extensions`.
3.  Enable "Developer mode" in the top right corner.
4.  Click "Load unpacked" and select the directory where you saved the source code.
5.  The extension is now installed and ready to use.

## Usage

1.  Navigate to any webpage with text.
2.  Double-click on a word you want to look up.
3.  A small pop-up will appear with the definition and other information.
4.  Click the speaker icon to hear the pronunciation.
5.  Click anywhere outside the pop-up to close it.

## Technologies Used

-   **HTML, CSS, JavaScript**: The core technologies for building the Chrome extension.
-   **Free Dictionary API**: Used to fetch word definitions and phonetic transcriptions.
-   **Chrome Extension APIs**: Utilized for creating the pop-up and interacting with webpages.
-   **Chrome Text-to-Speech (TTS) API**: Used for the audio pronunciation feature.
